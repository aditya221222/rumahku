# RUMAHKU — Our Life, Our Plans, Our Future

Smart Family Life Management Platform untuk suami & istri: keuangan, anggaran, tagihan, tabungan, Rencana Kita, Sedekah Kita, kalender, laporan.

- **Aplikasi:** https://aditya221222.github.io/rumahku/
- **Data:** Google Sheets "RUMAHKU — Database" + folder Drive "RUMAHKU" milik akun keluarga (server Google Apps Script "RUMAHKU - Server Data"). Repo ini hanya berisi tampilan; tidak ada data keluarga di sini.
- Memperbarui tampilan: unggah ulang berkas hasil build ke repo ini (cabang `main`).
